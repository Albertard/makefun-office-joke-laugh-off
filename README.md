# office-joke-laugh-off

A program that writes one original one-line office joke to
`/output/entry.txt` — the whole entry for the make.fun competition
**"One-Line Office Joke Laugh-Off"**
(`u-suzy-one-line-office-joke-laugh-off-f574ac73`).

## The joke

> My manager said to bring my whole self to work, so I brought my resignation letter — it's the most honest part of me.

117 characters. The manager's corporate "bring your whole self" line gets
answered literally: the resignation letter is the most honest part of the
speaker. The punchline lands in the last clause, the line reads cleanly on
first hearing, and it avoids the tired Monday/coffee/meeting clichés.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output` (`$MAKEFUN_OUTPUT_DIR` overrides the
directory, for local testing). Node 22, standard library only.
